# Stage Review Records

Each stage review records:

- Artifact or implementation reviewed
- Reviewers and review lenses
- Verification performed
- Findings by severity
- Required remediation
- Disposition and evidence
- Gate decision: pass or fail

A stage cannot pass while any unresolved material finding remains.

## Scope History

- `01-scope.md` records the original G1 pass.
- `03-spec.md` records why the resulting oversized G3 candidate failed delivery feasibility and reopened scope.
- `01b-rescope.md` is the passed replacement G1 review and supersedes the original scope decision. The original artifact versions remain historical Git/review evidence.
- `02b-prd.md` is the passed replacement G2 review. It records the clean replacement PRD, every failed exact-hash cycle, conflict-inference and abort/throttle remediations, unanimous final content pass, and final metadata-hash proof.
